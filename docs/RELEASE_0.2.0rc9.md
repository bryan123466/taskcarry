## 简体中文

本次更新让你把已经在做的工作接入项目管家。可以从一个项目、两个原对话开始。

- **先选项目，再选对话。** 解压完整包，在 AI 工具里打开 TaskCarry 文件夹。管家可以根据你允许查看的对话标题给建议，你也可以自己选。给每个选中的原对话贴同一段加入提示，继续在原处工作。
- **随时知道谁加入了。** 回到管家对话问「最近有哪些对话加入了？」它会根据回执列出职责、进度和下一步。同一对话重复加入只计一次。已经开启定时治理的项目也会在项目报告里看到这些变化。
- **本地工作，按需协作。** 你可以继续在本机工作、备份选定资料、邀请另一台电脑或另一款 AI，也可以接受邀请，加入一个已经使用 TaskCarry 治理的项目。
- **换 AI 或电脑时接着做。** 告诉目标端管家「我想把另一台电脑上的这个项目迁到这里，由你接任集成治理。请在这里重建原来的工作线」。也可以点名只迁哪些工作线。管家先从已保存的决定、版本、成果和未完成工作还原进度，指出还缺什么，等你确认后再交接主写。在无人机演练中，新加入的 Gemini 先交回一份文档，再从记录中找回 5 项任务和 4 个专业工作区的进度，由原管家核对。此次演练由原管家保有主写权。
- **Windows x64 套件自带 Python 和 Git。** 解压后从管家对话开始。如果管家提示缺少 Git 或 Python，建议安装缺少的工具后继续。

## English

Connect work already under way to a project manager. One project and two existing chats are enough to get started.

- **Choose the project and its chats.** Extract the full package and open the TaskCarry folder in your AI tool. The manager can suggest chats from the titles you allow it to see, or you can choose them yourself. Paste the same invitation into each chosen chat and keep working there.
- **See who joined.** Ask the manager “Which chats have joined?” It uses each chat’s receipt to report its role, progress and next step. Repeating the invitation counts the chat once. Projects with scheduled governance also see arrivals in their project report.
- **Choose how to collaborate.** Continue locally, back up selected materials, invite another computer or AI, or accept an invitation to a project already managed with TaskCarry.
- **Move to another AI or computer.** Tell the manager at the destination which project or workstreams to rebuild and whether it should take over integration. It traces saved decisions, revisions, results and unfinished work, identifies gaps, and waits for your confirmation before transferring write authority. In the drone exercise, a new Gemini chat delivered a document, then traced five tasks across four specialist workspaces using the project records. The original manager checked its account and retained write authority.
- **The Windows x64 package includes Python and Git.** Start in the manager chat. If it reports a missing tool, install that tool and continue.

## 繁體中文

本次更新讓你把已經在做的工作接入專案管家。可以從一個專案、兩個原對話開始。

- **先選專案，再選對話。** 解壓縮完整套件，在 AI 工具裡開啟 TaskCarry 資料夾。管家可依你允許查看的對話標題提出建議，你也可以自選。在每個選定的原對話貼上同一段加入提示，繼續在原處工作。
- **隨時知道誰加入了。** 回到管家對話問「最近有哪些對話加入了？」它會依據回執列出職責、進度和下一步。同一對話重複加入只計一次。已啟用定時治理的專案也會在報告裡看到這些變化。
- **在本機工作，視需要協作。** 你可以繼續在本機工作、備份選定資料、邀請另一台電腦或另一款 AI，也可以接受邀請，加入已經使用 TaskCarry 治理的專案。
- **換 AI 或電腦時接著做。** 告訴目標端管家「我想把另一台電腦上的這個專案遷到這裡，由你接任整合治理。請在這裡重建原來的工作線」。也可以指名只遷哪些工作線。管家先從已儲存的決定、版本、成果與未完成工作還原進度，指出缺項，等你確認後再交接主寫。在無人機演練中，新加入的 Gemini 先交回一份文件，再從記錄中找回 5 項任務和 4 個專業工作區的進度，由原管家核對。此次演練由原管家保有主寫權。
- **Windows x64 套件內含 Python 和 Git。** 解壓縮後從管家對話開始。如果管家提示缺少 Git 或 Python，建議安裝缺少的工具後繼續。
