# Start with your existing Codex project

TaskCarry adds a dedicated governance chat to work you already do in Codex. Your existing files, decisions and useful working chats stay in place. Governance maintains project memory and continuity, with an initial project assessment and optional ongoing coordination.

1. [Create the TaskCarry folder and send the single setup prompt](windows-example.md#install).
2. Let governance inherit the chosen project and complete working-window Git/MCP connections, local governance saving, original-chat scheduling and official update checking.
3. Review its actual acceptance report and continue in your normal working chats.

Additional specialists may be zero. Historical-reference chats need no active connection. A missing native capability is shown as a specific pending step, and an interrupted setup continues its checklist.

Already installed? Use the [update prompt](updating.md) in the original governance chat. [Daily operation](operation-manual.md) explains how to save and continue; [manual fallback](manual-setup.md) contains commands only when needed.
