# Start with your existing Codex project

TaskCarry adds a dedicated governance chat to work you already do in Codex. Your existing files, decisions and useful working chats stay in place. Governance maintains project memory and continuity, with an initial project assessment and optional ongoing coordination.

1. **Start a project manager chat.** Extract the ZIP into an empty folder. Follow the [folder-opening instructions and opening prompt](windows-example.md#install) to start a manager chat using it. In Codex, select the folder with **Ctrl+O** on Windows or **⌘O (Command+O)** on Mac, then start a new chat using it. If you want to join another project that already uses TaskCarry, you can tell the manager right away.
2. **Invite your working chats.** The manager gives you a message to paste. Choose from the projects and chats it suggests, or skip the suggestions and paste the message into the chats you want to include. Once a chat joins, carry on working there. To add another chat later, ask the manager for the message and where to paste it. With scheduled checks on, the manager picks up new chats at its next check and tells you who joined. You can also ask “Which chats have joined?”
3. **Get to work and let the manager follow up.** Review the project overview and next steps, then continue in your working chats. Enable scheduled check-ins, and ask the manager to help set up private GitHub backups, collaboration with other AIs or computers, or project migration as needed.

Additional specialists may be zero. Historical-reference chats need no active connection. A missing native capability is shown as a specific pending step, and an interrupted setup continues its checklist.

Already installed? Use the [update prompt](updating.md) in the original governance chat. [Daily operation](operation-manual.md) explains how to save and continue; [manual fallback](manual-setup.md) contains commands only when needed.
