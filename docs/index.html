Keep existing work connected, understood and recoverable.

TaskCarry gives projects already advancing in AI chats an independent governance home. It inherits confirmed decisions, understands selected new progress, keeps working chats aligned and verifies what has actually been saved or restored. Keep working in your existing chats; ongoing project coordination is your choice.

01

Understand the project

Retain source identities, decisions and dependencies. Distinguish observed material from AI understanding, and preserve finished history and unfinished positions.

02

Keep workbenches aligned

Publish exact private guidance without replacing professional instructions or Git WIP. Verify the view each working chat actually reads.

03

Continue and recover

Record bounded cycles and actual effects, resume missing steps after interruption, and verify selected recovery sets before any writer handoff.

Core + capability layer + your project

Core supplies verifiable local operations. The capability layer combines four packaged Skills, project methods and tools available in your host. Your project layer retains facts, decisions, task relationships, state, objects, files and progress. Updating public tools preserves that project memory. Core can be reinstalled; the project and its actual capability versions need recoverable coverage.

Your host supplies the AI model and permissions. Governance interprets permitted sources and maintains continuity; you retain project direction and business acceptance. A shared project brain means maintained identity, rules and evidence, not a copied model or every chat sharing one context.

Business results retain exact delivery relationships

Three steps establish the complete workflow

  1. Establish governance. Extract the complete product under toolkit in a local TaskCarry folder, open an independent Codex chat in the outer folder and send the main prompt.
  2. Complete setup through conversation. Governance inherits selected work; verifies local Git, native MCP and workbench consumption; performs its first cycle and a recovery rehearsal; and configures one morning report plus one or two absorption slots and official update checks.
  3. Review the evidence and continue. Receive the project/chat/task map, actual results, remaining conditions and next actions. Configuration readback, natural triggering, AI execution and report delivery remain separate evidence.
