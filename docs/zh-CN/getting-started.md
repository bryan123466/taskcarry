# 从已有 Codex 项目开始

TaskCarry 为正在进行的工作增加独立治理窗口。原有文件、决定和有用对话保留；总控维护项目记忆与接续，首次给出项目判断和建议，长期项目协调可选。

1. [建立 TaskCarry 文件夹并发送完整接入提示词](windows-example.md#install)。
2. 由总控继承所选项目，完成专业窗口 Git/MCP、本地治理保存、原窗口调度与官方更新检查。
3. 查看实际验收报告，继续在原来的工作窗口推进。

新增专业窗口可以为零，历史参考对话无需活跃接入。宿主能力不足会列出明确缺步；中断后从清单接续。

已有安装请在原治理窗口使用[更新提示词](updating.md)。[日常操作](operation-manual.md)说明如何保存与继续，[手动后备](manual-setup.md)仅在需要时提供命令。
