# 从已有 Codex 项目开始

TaskCarry 为正在进行的工作增加独立治理窗口。原有文件、决定和有用对话保留；总控维护项目记忆与接续，首次给出项目判断和建议，长期项目协调可选。

1. **开一个项目管家对话。** 把 ZIP 解压到一个空文件夹，按[文件夹打开方式与开场提示](windows-example.md#install)新开一个使用这个文件夹的管家对话。Codex 用 Windows **Ctrl+O** 或 Mac **⌘O（Command+O）** 选择文件夹，再开新对话。如果你要加入另一个已经使用 TaskCarry 治理的项目，也可以一开始就告诉管家。
2. **让工作对话加入。** 管家会直接给你一段加入提示。你可以从推荐的项目和对话中选，也可以跳过推荐，把提示直接贴到想加入的对话里。加入后，各个对话都可以在原处继续工作。以后想加新对话，告诉管家，它会给你提示和贴法。开启定时治理后，管家会在下次检查时收录并告诉你谁加入了。想确认时，直接问「最近有哪些对话加入了？」
3. **开始工作，让管家持续跟进。** 看管家整理的项目近况和下一步，回工作对话继续。建议开启定时治理，按需要让管家协助设置 GitHub 私有仓库备份、其他 AI 或电脑协作，以及项目迁移。

新增专业窗口可以为零，历史参考对话无需活跃接入。宿主能力不足会列出明确缺步；中断后从清单接续。

已有安装请在原治理窗口使用[更新提示词](updating.md)。[日常操作](operation-manual.md)说明如何保存与继续，[手动后备](manual-setup.md)仅在需要时提供命令。
