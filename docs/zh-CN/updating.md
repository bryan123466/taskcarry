# 在原治理窗口完成更新

[首次安装](windows-example.md) · [维护参考](governance-maintenance.md)

把下面提示词发给本项目原来的治理窗口：

> 请按我已选择的通道和维护偏好，检查 TaskCarry 官方发行来源；若我提供了产品包，先核对它的精确身份。读取相应说明，与实际运行包、受管方法和我的项目规则比较，说明适用性及最小必要更新。
>
> 在本次更新授权范围内准备并执行适用维护，保留原状态来源、任务、检查点、决定、工作窗口、定制配置和未完成工作。替换包时使用单独准备的候选运行环境，并保留旧环境供复核恢复。先预览受管文件和项目配置变更，保全定制，再核对受影响的宿主连接。遇到具体冲突或必须由我操作的宿主动作时，只给当前一步及准确目标。
>
> 中断后先核对已产生效果，再续剩余步骤。最后告诉我改了什么、保留了什么、是否可继续工作和还需什么操作。不要为了刷新项目记忆而重装、初始化另一个项目或合并业务分支。

日常治理已经承担官方通道读取与更新评估。检查不等于安装；离线时说明远端未核实，无变化不重复维护。候选版或稳定版按你的通道筛选，同版本不同内容要核对身份冲突。

产品提供共享内核和维护的方法，项目自己的规则与记忆持续保留。公开发行、本机安装、受管文件更新和运行中宿主实际加载分别记录；用户无需在每份操作文档中反复比较版本号。

继续更新时说：**“请接续 TaskCarry 更新，先核对已完成效果，只补剩余步骤。”** 完整版本差异放在[发行参考](../RELEASE_0.2.0rc7.md)，具体命令只在[手动后备](manual-setup.md)查阅。
