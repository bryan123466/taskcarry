# TaskCarry 三步上手

[更新与接续](updating.md) · [手动后备](manual-setup.md) · [反馈示例](user-feedback-examples.md) · [无人机项目实例](../../examples/vision-drone-governance/README.md) · [English](../en/windows-example.md) · [繁體中文](../zh-TW/windows-example.md)

你在原来的 AI 对话里继续写代码、做设计、整理资料。另开一个「项目管家」对话，让它帮你了解各项工作做到哪里、衔接不同对话的成果，并找回之前的决定和经验。已有管家或正在升级，请从[更新与接续](updating.md)进入。

## 1. 解压 TaskCarry，开一个管家对话

**① 解压。** 把下载的 ZIP 解压到一个空文件夹，比如 D 盘里新建的文件夹。

**② 开一个管家对话。** 按你使用的工具，选择刚才解压到的文件夹，新开一个使用这个文件夹的对话。这个对话就是项目管家。

| 你使用的工具 | 怎么打开 |
|---|---|
| **Codex 桌面版** | Windows 按 **Ctrl+O**，Mac 按 **⌘O（Command+O）**，选择解压文件夹，再新开一个使用这个文件夹的对话。 |
| **WorkBuddy** | 点击「新建任务」，在输入框下方设置「工作目录」，选择解压文件夹，再发送下面的开场提示。 |
| **Claude Code（CC，桌面版）** | 在 Claude 桌面应用中切换到 **Code**，新建本地会话，选择解压文件夹。 |
| **Claude Code（CC）／Gemini CLI／Kimi Code CLI（终端版）** | 在 Windows PowerShell 或 Mac 终端里，先运行 `cd "解压文件夹的完整路径"`。再按所用工具运行对应命令：CC 用 `claude`，Gemini CLI 用 `gemini`，Kimi Code CLI 用 `kimi`。 |
| **DeepSeek／GLM（通过 CC 或 WorkBuddy 使用）** | 已在 CC 中配置好模型的，按上面的 CC 方式打开。在 WorkBuddy 中使用这些模型的，按 WorkBuddy 方式打开。 |

**③ 把这段话贴给新对话。**

> 请在这个文件夹里找到 TaskCarry 的使用说明，帮我设好项目管家。如果这里已经有管家，就从原处接续。你可以根据我同意查看的对话标题推荐项目和对话，也可以由我自己挑。请直接给我一段加入提示，让我贴给想纳入的工作对话。只读我选择分享的工作内容。

管家会按包内说明完成安装和设置，再给你加入提示。你可以从它推荐的项目和对话中选，也可以直接说「给我加入提示，对话我自己挑」。需要你点击或确认时，管家会告诉你怎么做。

如果管家提示缺少 Git 或 Python，建议安装缺少的工具后继续。[Git](https://git-scm.com/downloads) · [Python 3.11+](https://www.python.org/downloads/)

## 2. 把加入提示贴到你选的工作对话里

**① 把加入提示贴给工作对话。** 管家会直接给你一段可以复制的提示。把它贴到每个想加入的对话，各贴一次。已有工作就用原对话，新任务也可以另开对话。

**② 跟着管家完成连接。** 管家会协助设置。需要选择工作文件夹、保存工作或重启 AI 工具时，它会告诉你具体怎么做。连好后，每个工作对话会说明自己负责什么、上次做到哪里、下一步做什么。新对话则由你告诉它要负责哪项工作。

**③ 确认哪些对话已加入，继续工作。** 你可以问管家「哪些对话已经加入了？」它会列出每个对话的职责、进度和下一步。如果少了一个，告诉它对话名称，管家会帮你查还差哪一步。

以后要加新对话，跟管家说「我想再加一个对话」，它会给你提示和操作方法。开了定时治理，贴好后管家会在下一次检查时自动收录并告诉你。

**无人机项目示例。** 你把同一段加入提示分别贴给「软件开发」和「产品验收」。软件对话说“演示改好了”，产品对话说“已经验过了”。你问管家“产品验过的是软件刚改的那一版吗？”管家会核对两边的版本和验收记录，告诉你验过哪一版、这次修改是否已进入大家共用的版本。后续再有修改，它也会提醒哪些地方需要重验。

## 3. 开始工作，让管家持续跟进

**① 看看管家整理的项目情况**

对话接好后，管家会整理一份项目概况。你也可以直接问它：

> 帮我看看项目现在做到哪里了，接下来应该先做什么？

| 你想知道什么 | 管家会告诉你 |
|---|---|
| **项目现在怎么样了？** | 目前的目标、已经完成的工作，还有哪些事情没做完或卡住了。 |
| **各个对话在做什么？** | 哪个对话负责哪项工作、上次做到哪里、接下来准备做什么。 |
| **哪些事情已经安排好了？** | 工作对话是否接好、项目记录保存在哪里，以及还有哪些设置需要完成。 |
| **我接下来该做什么？** | 建议先去哪个对话推进什么工作，以及哪些事情需要你来决定。 |

你可以回到工作对话说「继续上次的工作」。遇到不清楚的地方，也可以问管家「这件事哪个对话已经做过了？」或「上次遇到类似问题，是怎么解决的？」

**② 建议开启定时跟进**

让管家定期了解已加入对话的进展，整理新的成果、决定和经验，并提醒你需要处理的事情。你可以说：

> 帮我开启定时治理，建议一个适合这个项目的检查和汇报时间。

管家会根据你使用的 AI 工具给出设置方法，和你确认检查及汇报时间。开启后，你继续在工作对话里做事，管家按约定跟进；以后新增的对话，也会在贴好加入提示后的下一次检查中收录。

需要调整时，直接说「改成每天晚上汇报」或「先暂停定时跟进」即可。

**③ 按需要开启线上备份、其他 AI 或电脑协作**

管家会结合你的项目，建议是否需要线上备份或跨电脑、跨 AI 协作。项目需要长期保存，或者准备换电脑、与别人协作时，建议把重要文件和整理好的项目记录备份到**你自己的 GitHub 私有仓库**。

你可以直接告诉管家想做什么：

| 你想做的事 | 可以对管家这样说 |
|---|---|
| **把重要资料备份到线上** | 「帮我把这个项目的重要文件和项目记录备份到我自己的 GitHub 私有仓库，带我完成配置。」 |
| **让另一个 AI 或另一台电脑加入** | 「我想让另一个 AI／另一台电脑一起做这个项目，请帮我安排分工和接入步骤。」 |
| **加入别人已经在管理的项目** | 「我要作为协作成员，加入一个已经使用 TaskCarry 管理的项目，请告诉我需要向对方管家取得什么。」 |
| **换个 AI 或电脑接着管理项目** | 「我想把原本在另一个 AI 或另一台电脑上的集成治理迁到这里，由你接任集成治理。请帮我在本地重建原来完整的工作链。」只迁部分工作时，再说出要迁哪些对话。 |

这些安排可以按需要组合，也可以以后再开启。管家会给出具体步骤，需要登录账号、选择共享资料或新开工作对话时，会告诉你在哪里操作。
