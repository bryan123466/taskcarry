# 從既有 Codex 專案開始

TaskCarry 為正在進行的工作增加獨立治理視窗。既有檔案、決定與有用對話保留；總控維護專案記憶與接續，首次提供專案判斷與建議，長期專案協調可選。

1. [建立 TaskCarry 資料夾並傳送完整接入提示詞](windows-example.md#install)。
2. 由總控繼承所選專案，完成專業視窗 Git/MCP、本機治理儲存、原視窗排程與官方更新檢查。
3. 查看實際驗收報告，繼續在原來的工作視窗推進。

新增專業視窗可以為零，歷史參考對話無需活躍接入。宿主能力不足會列出明確缺步；中斷後從清單接續。

既有安裝請在原治理視窗使用[更新提示詞](updating.md)。[日常操作](operation-manual.md)說明如何儲存與繼續，[手動後備](manual-setup.md)僅在需要時提供指令。
