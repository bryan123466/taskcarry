# 從既有 Codex 專案開始

TaskCarry 為正在進行的工作增加獨立治理視窗。既有檔案、決定與有用對話保留；總控維護專案記憶與接續，首次提供專案判斷與建議，長期專案協調可選。

1. **開一個專案管家對話。** 把 ZIP 解壓縮到一個空資料夾，按照[資料夾開啟方式與開場提示](windows-example.md#install)開啟一個使用這個資料夾的管家對話。Codex 用 Windows **Ctrl+O** 或 Mac **⌘O（Command+O）** 選擇資料夾，再開啟新對話。如果你要加入另一個已經使用 TaskCarry 治理的專案，也可以一開始就告訴管家。
2. **讓工作對話加入。** 管家會直接給你一段加入提示。你可以從推薦的專案和對話中選，也可以跳過推薦，把提示直接貼到想加入的對話裡。加入後，各個對話都可以在原處繼續工作。以後想加新對話，告訴管家，它會給你提示與貼法。開啟定時治理後，管家會在下次檢查時收錄並告訴你誰加入了。想確認時，直接問「最近有哪些對話加入了？」
3. **開始工作，讓管家持續跟進。** 看管家整理的專案近況與下一步，回工作對話繼續。建議開啟定時治理，按需要讓管家協助設定 GitHub 私人儲存庫備份、其他 AI 或電腦協作，以及專案移轉。

新增專業視窗可以為零，歷史參考對話無需活躍接入。宿主能力不足會列出明確缺步；中斷後從清單接續。

既有安裝請在原治理視窗使用[更新提示詞](updating.md)。[日常操作](operation-manual.md)說明如何儲存與繼續，[手動後備](manual-setup.md)僅在需要時提供指令。
