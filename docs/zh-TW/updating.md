# 在原治理視窗完成更新

[首次安裝](windows-example.md) · [維護參考](governance-maintenance.md)

將以下提示詞傳送給本專案原來的治理視窗：

> 請依我已選擇的通道與維護偏好，檢查 TaskCarry 官方發行來源；若我提供了產品套件，先核對其精確身分。讀取相關說明，與實際執行套件、受管方法及我的專案規則比較，說明適用性與最小必要更新。
>
> 於本次更新授權範圍內準備並執行適用維護，保留原狀態來源、任務、檢查點、決定、工作視窗、自訂設定與未完成工作。替換套件時使用獨立準備的候選執行環境，並保留舊環境供複核恢復。先預覽受管檔案與專案設定變更，保全自訂內容，再核對受影響的宿主連線。遇到具體衝突或必須由我操作的宿主動作時，只給目前一步及準確目標。
>
> 中斷後先核對已產生效果，再續剩餘步驟。最後告訴我改了什麼、保留了什麼、是否可繼續工作及還需什麼操作。不要為了更新專案記憶而重裝、初始化另一個專案或合併業務分支。

日常治理已承擔官方通道讀取與更新評估。檢查不等於安裝；離線時說明遠端未核實，無變化不重複維護。候選版或穩定版依你的通道篩選，同版本不同內容要核對身分衝突。

產品提供共用核心與維護的方法，專案自己的規則與記憶持續保留。公開發行、本機安裝、受管檔案更新和執行中宿主實際載入分別記錄；使用者無需在每份操作文件中反覆比較版本號。

繼續更新時說：**「請接續 TaskCarry 更新，先核對已完成效果，只補剩餘步驟。」** 完整版本差異放在[發行參考](../RELEASE_0.2.0rc7.md)，具體指令只在[手動後備](manual-setup.md)查閱。
