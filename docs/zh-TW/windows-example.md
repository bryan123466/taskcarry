# TaskCarry 三步上手

[更新與接續](updating.md) · [手動後備](manual-setup.md) · [回饋範例](user-feedback-examples.md) · [無人機專案實例](../../examples/vision-drone-governance/README.md) · [English](../en/windows-example.md) · [简体中文](../zh-CN/windows-example.md)

你在原來的 AI 對話裡繼續寫程式、做設計、整理資料。另開一個「專案管家」對話，讓它幫你了解各項工作做到哪裡、銜接不同對話的成果，並找回之前的決定與經驗。已有管家或正在升級，請從[更新與接續](updating.md)進入。

## 1. 解壓縮，開一個專案管家對話

**① 解壓縮 ZIP。** 選一個空資料夾，把套件解壓縮到裡面。例如，可以在 D 槽建一個空資料夾。

**② 開一個管家對話。** 按照你使用的工具，選擇剛才解壓縮到的資料夾，開啟一個使用這個資料夾的新對話。這個對話就是專案管家。

| 你使用的工具 | 怎麼開啟 |
|---|---|
| **Codex 桌面版** | Windows 按 **Ctrl+O**，Mac 按 **⌘O（Command+O）**，選擇解壓縮資料夾，再開啟一個使用這個資料夾的新對話。 |
| **WorkBuddy** | 點選「新建任務」，在輸入框下方設定「工作目錄」，選擇解壓縮資料夾，再傳送下面的開場提示。 |
| **Claude Code（CC，桌面版）** | 在 Claude 桌面應用程式中切換到 **Code**，建立本機會話，選擇解壓縮資料夾。 |
| **Claude Code（CC）／Gemini CLI／Kimi Code CLI（終端版）** | 在 Windows PowerShell 或 Mac 終端機裡，先執行 `cd "解壓縮資料夾的完整路徑"`。再依所用工具執行對應指令：CC 用 `claude`，Gemini CLI 用 `gemini`，Kimi Code CLI 用 `kimi`。 |
| **DeepSeek／GLM（透過 CC 或 WorkBuddy 使用）** | 已在 CC 中設定好模型的，按照上面的 CC 方式開啟。在 WorkBuddy 中使用這些模型的，按照 WorkBuddy 方式開啟。 |

**③ 把這段話貼到新對話裡。**

> 請在這個資料夾裡找到 TaskCarry 的使用說明，幫我設定專案管家。如果這裡已經有管家，就從原處接續。你可以根據我同意查看的對話標題推薦專案和對話，也可以由我自己挑。請直接給我一段加入提示，讓我貼到想納入的工作對話。只讀取我選擇分享的工作內容。

管家會按照套件說明完成安裝與設定，再給你加入提示。你可以從它推薦的專案與對話中選，也可以直接說「給我加入提示，對話我自己挑」。需要你點選或確認時，管家會告訴你怎麼做。

如果管家提示缺少 Git 或 Python，建議安裝缺少的工具後繼續。[Git](https://git-scm.com/downloads) · [Python 3.11+](https://www.python.org/downloads/)

## 2. 把加入提示貼到你想納入的工作對話

**① 把加入提示貼給工作對話。** 管家會直接給你一段可以複製的提示。把它貼到每個想加入的對話，各貼一次。既有工作就用原對話，新任務也可以另開對話。

**② 跟著管家完成連線。** 管家會協助設定。需要選擇工作資料夾、儲存工作或重啟 AI 工具時，它會告訴你具體怎麼做。連好後，每個工作對話會說明自己負責什麼、上次做到哪裡、下一步要做什麼。新對話則由你告訴它要負責哪項工作。

**③ 確認哪些對話已加入，繼續工作。** 你可以問管家「哪些對話已經加入了？」它會列出每個對話的職責、進度與下一步。如果少了一個，告訴它對話名稱，管家會幫你查還差哪一步。

以後想加新對話，跟管家說「我想再加一個對話」，它會給你提示與操作方法。開啟定時治理後，貼好提示，管家就會在下次檢查時自動收錄並告訴你。

**無人機專案範例。** 你把同一段加入提示分別貼給「軟體開發」和「產品驗收」。軟體對話說「展示改好了」，產品對話說「已經驗過了」。你問管家「產品驗過的是軟體剛改的那一版嗎？」管家會核對兩邊的版本與驗收紀錄，告訴你驗過哪一版、這次修改是否已經納入大家共用的版本。之後再有修改，它也會提醒哪些地方需要重驗。

## 3. 開始工作，讓管家持續跟進

**① 看看管家整理的專案情況**

對話接好後，管家會整理一份專案概況。你也可以直接問它：

> 幫我看看專案現在做到哪裡了，接下來應該先做什麼？

| 你想知道什麼 | 管家會告訴你 |
|---|---|
| **專案現在怎麼樣了？** | 目前的目標、已經完成的工作，還有哪些事情沒做完或卡住了。 |
| **各個對話在做什麼？** | 哪個對話負責哪項工作、上次做到哪裡、接下來準備做什麼。 |
| **哪些事情已經安排好了？** | 工作對話是否接好、專案紀錄儲存在哪裡，以及還有哪些設定需要完成。 |
| **我接下來該做什麼？** | 建議先去哪個對話推進什麼工作，以及哪些事情需要你來決定。 |

你可以回到工作對話說「繼續上次的工作」。遇到不清楚的地方，也可以問管家「這件事哪個對話已經做過了？」或「上次遇到類似問題，是怎麼解決的？」

**② 建議開啟定時跟進**

讓管家定期了解已加入對話的進展，整理新的成果、決定與經驗，並提醒你需要處理的事情。你可以說：

> 幫我開啟定時治理，建議一個適合這個專案的檢查與回報時間。

管家會根據你使用的 AI 工具給出設定方法，和你確認檢查及回報時間。開啟後，你繼續在工作對話裡做事，管家按約定跟進；以後新增的對話，也會在貼好加入提示後的下一次檢查中收錄。

需要調整時，直接說「改成每天晚上回報」或「先暫停定時跟進」即可。

**③ 按需要開啟線上備份、其他 AI 或電腦協作**

管家會根據你的專案，建議是否需要線上備份或跨電腦、跨 AI 協作。專案需要長期保存，或準備換電腦、與別人協作時，建議把重要檔案和整理好的專案紀錄備份到**你自己的 GitHub 私人儲存庫**。

你可以直接告訴管家想做什麼：

| 你想做的事 | 可以對管家這樣說 |
|---|---|
| **把重要資料備份到線上** | 「幫我把這個專案的重要檔案和專案紀錄備份到我自己的 GitHub 私人儲存庫，帶我完成設定。」 |
| **讓另一個 AI 或另一台電腦加入** | 「我想讓另一個 AI／另一台電腦一起做這個專案，請幫我安排分工和接入步驟。」 |
| **加入別人已經在管理的專案** | 「我要以協作成員身分，加入一個已經使用 TaskCarry 管理的專案，請告訴我需要向對方管家取得什麼。」 |
| **換個 AI 或電腦接著管理專案** | 「我想把原本在另一個 AI 或另一台電腦上的整合治理移到這裡，由你接任整合治理。請幫我在本機重建原來完整的工作流程。」若只移轉部分工作，再說出要移轉哪些對話。 |

這些安排可以按需要組合，也可以以後再開啟。管家會給出具體步驟，需要登入帳號、選擇分享資料或開啟新的工作對話時，會告訴你在哪裡操作。
