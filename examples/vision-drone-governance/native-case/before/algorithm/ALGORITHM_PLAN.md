# 离线障碍物事件与评估计划

本阶段为虚构无人机项目定义离线障碍物事件，并用手工构造的样例检查协议与评估逻辑。初步类别为墙面（`wall`）、立柱（`column`）和箱体（`box`）。室内外通用是早期设想，两类场景的数据覆盖和硬件适用性均待验证。

## 事件协议

每条事件对应一帧中的一个候选障碍物区域。一帧可以有零条、一条或多条事件。以下字段是算法侧提议，软件和硬件侧的采用情况待确认。

| 字段 | 离线含义 |
| --- | --- |
| `frame_id` | 帧清单中的非空字符串标识。同一帧的多条事件共用该标识。 |
| `label` | 候选类别，取 `wall`、`column` 或 `box`。 |
| `region` | 轴对齐矩形，包含 `x_min`、`y_min`、`x_max`、`y_max`。坐标相对于整帧图像归一化，以左上角为原点，横轴向右，纵轴向下，右边界和下边界分别可取 1。 |
| `confidence` | 取值范围为闭区间 [0, 1] 的候选分数。样例使用手工设定的分数。 |
| `timestamp_ms` | 相对合成序列起点的非负整数毫秒。每条事件沿用所属帧的时间。 |

`EVENT_SCHEMA.json` 校验单条候选事件的字段、类型和取值范围。读取时还需检查正面积条件 `0 ≤ x_min < x_max ≤ 1` 和 `0 ≤ y_min < y_max ≤ 1`。

## 合成样例

`SYNTHETIC_EVENTS.json` 的 `frames` 是按时间排列的帧清单，包含空帧以及每帧手工指定的 `reference_regions`。参考区域使用同一套类别与坐标规则。`candidate_events` 是供逐条校验的候选事件列表。

帧清单内的 `frame_id` 唯一，时间戳非递减。每条候选事件必须引用清单内的一帧，且两处的 `timestamp_ms` 必须一致。评估以帧清单为遍历依据，使只有参考框的帧和完全空白的帧也能进入评估。

## 离线评估方法

1. 固定样例版本、类别定义、置信度阈值和交并比（IoU）阈值。合成样例走查使用两个阈值均为 0.50 的配置，候选分数等于阈值时保留。IoU 按矩形交集面积除以并集面积计算。
2. 在每帧内按类别匹配。将保留的候选按置信度从高到低处理，分数相同则沿用事件列表顺序。每条候选选取同类别尚未匹配且 IoU 最高的参考框，IoU 相同则沿用参考框顺序。达到 IoU 阈值时建立一对一匹配。
3. 记录每类的匹配数（TP）、未匹配的保留候选数（FP）和未匹配的参考框数（FN）。如需汇总，使用 `TP / (TP + FP)` 计算精确率，使用 `TP / (TP + FN)` 计算召回率，分母为零时标记为不适用。保留帧号和匹配明细以便复核。

| 样例帧 | 按上述配置预期的处理 |
| --- | --- |
| `sim-000` | 空帧保留在遍历中。 |
| `sim-001` | 墙面候选与参考框匹配。 |
| `sim-002` | 同帧立柱和箱体分别匹配，多出的箱体候选记为误报。 |
| `sim-003` | 无候选的箱体参考框记为漏报。 |
| `sim-004` | 候选分数恰等于阈值，保留后因缺少参考框记为误报。 |
| `sim-005` | 立柱候选低于阈值被过滤，参考框记为漏报。 |

合成样例的证据范围限于字段、帧关联和评估规则。真实识别表现、运行时延、避障成功率和飞行能力均待实测。
