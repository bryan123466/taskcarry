# 项目接入后的离线接口核对

当前可继承的材料包括算法侧事件提案、六帧合成样例和离线评估规则。项目接入后，与软件、硬件一起核对以下接口约定。

| 待确认项 | 合成样例中的约定 | 接入后需明确的内容 |
| --- | --- | --- |
| 坐标含义 | `region` 是整帧归一化的左上原点边界框。 | 坐标绑定原始帧、裁剪帧还是缩放后帧，确认方向、坐标范围、边界语义和映射规则。 |
| 时间单位与来源 | `timestamp_ms` 是相对序列起点的整数毫秒，同帧事件共用。 | 确认采集侧和软件传递的原始单位、时钟及时间原点，确定采集时间与处理时间的取用和换算规则。 |
| 输入约束 | 输入是帧清单、手工标注区域及合成候选事件。 | 确认输入帧的分辨率、方向、像素格式、帧率范围与预处理方式，以及丢帧或乱序时的处理。 |
| 字段与帧关联 | 一个帧标识可对应多条候选。零候选帧由帧清单保留。 | 确认消费端接收的字段、标签枚举、帧标识来源、空帧表达和重复候选处理责任。 |

将确认结果记入接口表，并同步修订事件结构与样例。用同一份样例做一次生产端与消费端的离线联调，对照 `ALGORITHM_PLAN.md` 逐帧复核空帧保留、坐标与时间解释、同帧多候选读取和匹配结果。
