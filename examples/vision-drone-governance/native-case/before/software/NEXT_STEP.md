# 软件侧接续事项

离线示意已有三帧、四条合成事件。默认显示 `sim-003`，可以查看同帧两条事件和一个空区域，也可以切换模拟连接状态。 [监控示意](monitor.html)

## 待对齐

- 项目协调确认首阶段覆盖哪些室内或室外场景，以及需要展示的障碍物类别。
- 算法与软件确认 `frame_id` 的格式和唯一性范围、`label` 的类别字典，以及 `region` 的编码和参照画面。同帧多条事件的表示方式也需确认。 [事件接口草案](INTERFACE_DRAFT.json)
- 算法与软件统一置信度的含义与取值范围，以及时间戳对应的时点、时钟基准和单位。事件记录用什么顺序也待确认。
- 进入联调时，由软件与链路负责方约定连接状态代表哪条链路、状态从哪里获取、何时判定断开。

## 下一次对接

场景和字段确认后，用一小组合成事件做离线回放。按双方约定核对类别和区域映射、同帧多条事件的呈现、事件记录顺序，再更新界面和接口草案。
