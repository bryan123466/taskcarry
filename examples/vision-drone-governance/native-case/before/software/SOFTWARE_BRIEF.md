# 软件侧简报

“视觉识别与避障无人机”概念项目的地面监控界面已有一版离线示意。界面用合成事件展示障碍物类别、画面区域、模拟连接状态和事件记录。早期讨论涉及室内和室外，首阶段场景待项目协调确认。

## 界面

- 当前帧可切换。画面按左侧、中部、右侧排列，每个区域显示该帧落在此处的障碍物类别。
- 连接状态由页面控件模拟，可在“模拟已连接”和“模拟已断开”之间切换。
- 事件表按样例顺序列出帧标识、类别和区域，高亮当前帧对应的记录。

## 算法对接

事件暂用 `frame_id`、`label`、`region`。样例中每条事件表示一帧里的一个障碍物条目，同一帧可以有多条。样例使用字符串和左、中、右区域枚举，实际字段约定待对接。置信度和时间戳尚未统一。 [事件接口草案](INTERFACE_DRAFT.json)

在浏览器中打开示意页，默认帧 `sim-003` 会在中部显示箱体，在右侧显示围挡。 [监控示意](monitor.html)
