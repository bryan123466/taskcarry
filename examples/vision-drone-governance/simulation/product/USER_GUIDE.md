# RC8 v2 离线仿真使用说明

> 本页依据固定技术快照：九项独立浏览器检查、工程文件检查及公开副本三场景复演均通过。表述登记记录技术支持与公开文件引用；精确公开对象的验收由另行出具的独立公开内容复核回执决定，该回执单向引用本页与登记，不在这里重复可变审核状态。

## 打开并运行

1. 解压离线包，保留 `app/` 内的文件，在桌面 Chrome 本地打开 [`app/index.html`](../app/index.html)。
2. 在「场景／任务」选择空房间到达、固定障碍绕行或缺帧等待与恢复。
3. 点「重置」，等页首显示「就绪」「等待帧」并确认日志为空，再点「开始」。需要换场景时重新选择，并按上述顺序从起点启动。

（`PRODUCT-REPLAY-OFFLINE`、`PRODUCT-REPLAY-CONTROLS`）

## 查看相机、路线和缺帧

「局部相机」下方显示帧标识、像素摘要与当前检测。合成画面的检测框对应当前拍的墙面、立柱或箱体。对照「运行路线」看位置变化，用「逐拍记录」回看命令、检测和链路。（`PRODUCT-REPLAY-DETOUR`）

| 界面提示 | 读法 |
| --- | --- |
| 有效空帧 | 已收到有效的合成像素，检测列表为空。空房间首帧可观察到这一状态。 |
| 本拍缺帧 | 当前相机帧未交付，逐拍记录为 `HOLD`，位置保持。第一次缺帧时页首仍显示「链路已连接」。 |
| 模拟断流 | 缺帧场景的第二次连续缺帧触发这一状态，画面框清空。下一有效帧到来后页首恢复「链路已连接」，记录出现 `reconnected`。 |

（`PRODUCT-REPLAY-CLEAR`、`PRODUCT-REPLAY-DROP`）

## 暂停、重置与下载

运行中点「暂停」会停住当前拍与日志，点「继续」接着推进。重置前先保存需要的记录。点「重置」会回到本场景起点，恢复等待帧并清空逐拍记录。（`PRODUCT-REPLAY-CONTROLS`）

运行结束后点「导出 JSON」。三个场景分别下载 `rc8-drone-sim-v2-clear-room.json`、`rc8-drone-sim-v2-fixed-obstacle.json`、`rc8-drone-sim-v2-drop-and-recover.json`。文件按拍保留逻辑时标、帧摘要、检测、命令、位置、链路及终态。（`PRODUCT-REPLAY-EXPORT`）
