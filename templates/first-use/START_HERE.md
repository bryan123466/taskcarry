# TaskCarry

## 简体中文

**第一次使用**　把 ZIP 解压到一个空文件夹，按[各工具的打开方式](../../docs/zh-CN/windows-example.md)新开一个使用这个文件夹的管家对话。Codex 的快捷键是 Windows **Ctrl+O**、Mac **⌘O（Command+O）**，选好文件夹后再开新对话。把下面这段话贴给它。

> 请在这个文件夹里找到 TaskCarry 的使用说明，帮我设好项目管家。如果这里已经有管家，就从原处接续。你可以根据我同意查看的对话标题推荐项目和对话，也可以由我自己挑。请直接给我一段加入提示，让我贴给想纳入的工作对话。只读我选择分享的工作内容。

管家会按包内说明完成安装和设置，再给你加入提示。你可以从它的建议里选，也可以自己挑，把同一段提示贴给想加入的工作对话，然后继续在原处工作。以后要加新对话，跟管家说一声就好。 [三步操作手册](../../docs/zh-CN/windows-example.md)

如果管家提示缺少 Git 或 Python，建议安装缺少的工具后继续。

**已经有项目管家**　把新包单独解压，回到原治理对话，让它按[更新与接续](../../docs/zh-CN/updating.md)核对现有项目和版本。

## English

**First time here?** Extract the ZIP into an empty folder and follow the [instructions for your AI tool](../../docs/en/windows-example.md) to start a manager chat using that folder. In Codex, press **Ctrl+O** on Windows or **⌘O (Command+O)** on Mac, select the folder and start a new chat using it. Send this message.

> Find the TaskCarry instructions in this folder and set up my project manager. If I already have one here, continue with it. You may suggest projects and chats from titles I allow you to see, or I can choose the chats myself. Give me a single invitation I can paste into the chats I want to include. Only read the work I choose to share.

The manager follows the package instructions to install and configure TaskCarry, then gives you an invitation. Choose from its suggestions or pick the chats yourself. Paste the same invitation into each one and keep working there. Ask the manager whenever you want to add another chat. [Three-step guide](../../docs/en/windows-example.md)

If the manager reports that Git or Python is missing, install the missing tool and continue.

**Already using TaskCarry?** Extract the new package separately. Return to your existing governance chat and ask it to check your project and installed version using the [update guide](../../docs/en/updating.md).

## 繁體中文

**第一次使用**　將 ZIP 解壓縮到一個空資料夾，按照[各工具的開啟方式](../../docs/zh-TW/windows-example.md)開啟一個使用這個資料夾的管家對話。Codex 的快速鍵是 Windows **Ctrl+O**、Mac **⌘O（Command+O）**，選好資料夾後再開啟新對話。把下面這段話貼給它。

> 請在這個資料夾裡找到 TaskCarry 的使用說明，幫我設定專案管家。如果這裡已經有管家，就從原處接續。你可以根據我同意查看的對話標題推薦專案和對話，也可以由我自己挑。請直接給我一段加入提示，讓我貼到想納入的工作對話。只讀取我選擇分享的工作內容。

管家會按照套件說明完成安裝與設定，再給你加入提示。你可以從它的建議裡選，也可以自己挑，把同一段提示貼給想加入的工作對話，再回原對話繼續工作。以後想加新對話，告訴管家就好。 [三步操作手冊](../../docs/zh-TW/windows-example.md)

如果管家提示缺少 Git 或 Python，建議安裝缺少的工具後繼續。

**已經有專案管家**　請將新產品包單獨解壓縮，再回到原治理對話，請它依照[更新與接續](../../docs/zh-TW/updating.md)核對現有專案與版本。
